# The Great Indian WTF Quiz

A host-controlled, real-time game show built for a TV/projector and 25 participant phones.

## Locked game
- **18 questions**, 3 rounds of 6.
- **Round 1 — 3 True, 1 Bullshit:** reveal question, then A/B/C/D on separate host taps, then open voting.
- **Round 2 — What the Actual Fuck?!:** write-in guesses to bizarre true-news plot twists.
- **Round 3 — Who the Hell Am I?:** 5 progressive clues per celebrity with 500–100 point scoring.
- **Scores remain hidden until after questions 6, 12 and 18**, when all 25 segment totals and cumulative rankings are shown.
- Three synchronized views: private host, big screen, and players.

## Build status
Repository initialized. Application files, automated tests and a deployment workflow are being added in the next phase.

The host can control the entire quiz from their screen; players join from a link without installing anything.
